# 增量实现 /build

按 `.spec-flow-workspace/<feature>/plan.md` 中确认过的任务顺序实现，一次一个垂直切片，每片完成即自测。只实现 Task 关联的 AC，不顺手增加需求。

## 要做的事

1. **垂直切片**：每个切片走通「入口 → 逻辑 → 展示」一条完整链路，不做半截活。
2. **接口未就绪时不写 mock**：用 dev 内联假数据顶替——假数据必须符合业务公式（数量、金额、状态能对上）；路径实在造不出来时加 localhost 后门，并注明是临时后门、上线前删除。
3. **遵守 house-rules**：编码约定（spec-conventions）、改动范围（spec-scope-discipline）、证据规则（spec-evidence-rules）全程生效。
4. **每片自测**：写完一片立即用最小验证方式确认可用，再开下一片。
5. **不顺手扩大**：发现切片外的关联问题，记录下来汇报，不擅自修。

## 红线

- 禁止引入需求与方案之外的抽象、依赖或功能。
- 半成品不留尾巴：每个切片要么完成，要么回滚到干净状态。
